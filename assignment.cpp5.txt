Problem Statement: 
Every college faces the problem of lost items such as ID cards, wallets, keys, laptops, and 
mobile phones. This system makes finding lost items faster and more organized. 
Modules 
1. Student Login  
2. Report Lost Item  
3. Report Found Item  
4. Search Item  
5. Auto Match Lost & Found  
6. View All Records  
7. Delete Record  
8. Item Statistics  
9. Export Report  
10. Exit
